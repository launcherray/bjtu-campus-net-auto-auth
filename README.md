# BJTU Campus Net Auto Auth

适用于北京交通大学校园网的非官方 Windows 自动认证脚本，基于 PowerShell，支持开机认证、状态查看与本地凭据加密保存。

由 [launcherray](https://github.com/launcherray) 维护，使用 AI 辅助编写，以 [MIT 许可证](LICENSE) 发布。

## 项目声明

本项目为个人维护的非官方开源脚本，与北京交通大学及相关服务提供方不存在官方隶属、授权或背书关系。项目名称中的“北京交通大学”和“BJTU”仅用于说明适用场景。

**本项目不包含北京交通大学未公开的内部私有接口、服务端私有源码、内部文档或敏感代码，也不随仓库分发真实用户凭据。** 使用的认证请求均来源于普通用户可访问的校园网登录页面及其浏览器请求，用于自动完成常规认证流程。

本项目使用 AI 辅助编写。代码未复制或改写其他项目。本项目作为个人开源脚本分享，不提供绕过身份认证、计费或访问控制的功能。用户应使用本人有权使用的账号，并遵守适用的校园网使用规定。

## 功能

- 设置、更新及清除本机保存的校园网凭据。
- 查询认证状态；确认未认证时提交登录请求，已认证时跳过登录。
- 通过 Windows 任务计划程序在开机后执行认证。
- 显示认证进度、最近一次结果和重试倒计时，支持停止本次运行。
- 认证失败后按间隔重试，并支持禁用自启及卸载。

以上为当前代码提供的功能，不代表每项功能均已完成独立测试。

## 运行环境与验证范围

| 项目 | 说明 |
| --- | --- |
| 已实际使用的系统 | Windows 11 |
| 已实际使用的接入方式 | 校园有线网络、校园 Wi-Fi |
| 启动入口 | `Manage.cmd` 调用 Windows 自带的 `powershell.exe`（Windows PowerShell）；实际使用版本未单独记录 |
| 依赖 | Windows 任务计划程序及系统自带的 .NET 组件，无需额外安装 Python 或 Node.js |
| 权限 | 管理菜单需要管理员权限；开机认证任务以 SYSTEM 身份运行 |

工具不会代替 Windows 连接 Wi-Fi 或有线网络。计算机应先接入校园网，且用户拥有可用的校园网账号。

## 快速开始

1. 在本仓库页面选择 **Code → Download ZIP**，解压到普通文件夹；保留 `Manage.cmd` 与 `BJTUWebLogin.ps1` 在同一目录。
2. 双击 `Manage.cmd`，在 Windows 用户账户控制对话框中授予管理员权限。
3. 选择 **1「设置或更新校园网账号和密码」**。按校园网登录页的账号规则填写；需要运营商后缀时，按实际页面选择对应后缀。
4. 如需开机认证，选择 **2「开启开机自启」**。
5. 选择 **4「立即运行一次」**启动认证和状态窗口；选择 **5「检查当前认证状态」**查询状态；选择 **6「查看上次运行结果」**查看最近记录。

“立即运行一次”会启动一个认证流程；若认证失败，该流程仍会按下文所述间隔重试，直到确认成功或用户停止。

详细菜单、保存位置、更新和卸载方法见 [使用说明](使用说明.md)。

## 自启、重试与停止

启用自启后，认证任务在系统启动 15 秒后开始运行，无需等待用户登录 Windows。配置自启的用户登录 Windows 后 20 秒，另一个计划任务在认证流程仍运行时显示状态窗口。

首次登录前最多查询 18 次状态，查询失败后间隔 20 秒再试。确认终端未认证时，本轮最多提交一次登录请求并复查结果。本轮失败后，每隔 1 小时重试；后续每轮查询一次状态，确认未认证时最多提交一次登录请求。

确认认证成功后，本次流程退出。它不是登录成功后持续监控断线的常驻服务。关闭状态窗口或选择“停止并退出”会停止本次运行；需要同时关闭开机自启时，在管理菜单选择 **3**。

若认证页面启用验证码或更换不支持的认证方式，请改用 [校园网认证页](https://login.bjtu.edu.cn/) 手动认证。

## 隐私与凭据保护

- 账号和密码由用户在本机输入。当前代码中的网络请求目标为校园网登录服务 `login.bjtu.edu.cn`，认证时向该服务提交所需信息；没有向作者服务器上传数据。
- 安装副本位于 `C:\Program Files\BJTUWebLogin`，凭据位于其中的 `private\credential.bin`。
- 凭据使用 Windows DPAPI 的 `LocalMachine` 模式加密；凭据目录限制为 SYSTEM 和管理员访问。这种保护依赖本机安全与文件权限，不能防止拥有相应权限的本机进程读取凭据。
- 本地 `last-run.log` 记录最近一次状态、时间及重试时间，当前代码不主动将账号、密码或完整认证请求 URL 写入该日志。

更多说明及安全问题反馈方式见 [SECURITY.md](SECURITY.md)。

## 更新与卸载

更新下载目录中的脚本后，已启用自启的用户应重新选择 **2「开启开机自启」**，以更新已安装的脚本和任务配置。已保存的凭据可继续使用。

- **清除凭据并禁用自启：**选择 **7** 并确认。
- **自动卸载：**选择 **8**，依次输入 `Y`、`Y`、`UNINSTALL`。

**当前自动卸载还会删除下载目录中的 `Manage.cmd`、`BJTUWebLogin.ps1` 和 `使用说明.md`。** 在 Git 工作目录中执行会产生对应文件的删除变更。需要保留源码时，请按 [手动卸载步骤](使用说明.md#手动卸载) 清理计划任务和安装目录，并保留下载目录。
